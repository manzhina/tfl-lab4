# Regex Parser

Переписан с [Python](https://github.com/oFem1m/IU9-ToFL/tree/master/lab4) на C++. Также добавлено по 10 негативных и позитивных тестов.

### Зависимости
Для компиляции потребуется компилятор C++ (с поддержкой C++17 или выше).
Для тестирования потребуется Python 3.

Для запуска нужно скомпилировать программу, например:

```bash
g++ -o regex_cpp_parser regex_parser.cpp -std=c++17
```

После компиляции делаем:
```bash
./regex_cpp_parser
```
И вводим регулярное выражение для анализа.

Для запуска тестов нужно убедиться, что файл `regex_cpp_parser` успешно собран и запустить Python-скрипт:

```bash
python3 run_test.py
```
